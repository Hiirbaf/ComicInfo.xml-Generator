# Importación, edición y generación de metadatos ComicInfo.xml para cómics.

**El archivo se puede descargar desde la carpeta html.**

#### introducción
Este es un editor ligero de ComicInfo.xml generado mediante IA.
• Función de importación: Puedes importar directamente archivos existentes desde la parte superior para realizar modificaciones.
• Seguridad y privacidad: Se ejecuta totalmente de forma local; no se suben datos.
• Compatibilidad: Compatibilidad total con Komga, Tachiyomi y más.

#### Descripciones de los campos
- Nombre de la serie (Series): El título de toda la serie de manga
- Título (Title): Título específico de este volumen/capítulo
- Subtítulo / Título original / Nombre alternativo (AlternateSeries): Título del capítulo, título original en japonés o título alternativo en chino
- Número de episodios (Number): Qué capítulo/episodio, p. ej., «1050»
- Número de volumen (Volume): Número de volumen de una edición de un solo volumen; por ejemplo, «01»
- Idioma (Language): Códigos de idioma ISO, como zh, ja, en, es
- Equipo de traducción (ScanInformation): Registra el grupo de traducción o la fuente de escaneo
- Admite la importación de archivos ComicInfo.xml existentes para el rellenado automático.

#### Descripciones de los campos:
Para utilizarlo, coloca el archivo en el directorio raíz de tu archivo de cómic (ZIP o CBA); las aplicaciones compatibles, como Komga, podrán detectarlo.
