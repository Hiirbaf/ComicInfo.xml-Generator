🌸 Acerca de este proyecto

Este es un editor ligero de ComicInfo.xml.
• Función de importación：Puedes importar directamente archivos antiguos para modificarlos en la parte superior.
• Seguridad y privacidad：Se ejecuta exclusivamente de forma local, sin subir datos.
• Compatibilidad：Es totalmente compatible con Komga、Tachiyomi etc.
